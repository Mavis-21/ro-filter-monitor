BOARD MESSAGE FORMAT

One JSON line per reading

{"current_a":1.5,"flow_l_min":1.7,"pressure_bar":6.6,"raw_tds_ppm":520,"output_tds_ppm":34}

Send at 115200 baud about once per second. Raw and output TDS are two readings within the fourth sensor group. The Mac can confirm that numbers arrive; it cannot prove calibration or wiring quality from software alone.
